## 🧐 Tentang Proyek

Pada proyek kali ini, saya ingin membuat suatu model CNN RestNet-50 yang nantinya dapat mengenali gambar AI atau Asli. Kategori gambar yang dikumpulkan yaitu, gambar kartun
dan gambar orang. Modelnya akan disimpan ke dalam file "_best_model.pth_" agar bisa dimanfaatkan kembali hasil pelatihannya. Jumlah gambar yang digunakan untuk melakukan
pelatihan berjumlah 4600 dengan pembagian gambar AI dan gambar aslinya seimbang.
